## 7. Cross-border SG → JB / KL (feature + drivers)

### What the driver must have (2026 rules)
- VEP RFID tag, mandatory for all foreign vehicles since 1 Jul 2025; RM300 fine and vehicle held if invalid. Check at vep.jpj.gov.my.
- Road charge RM20 on entry; Touch 'n Go card with ≥ RM50 for tolls; Singapore tolls S$0.80 (Woodlands) / S$2.10 (Tuas).
- 3/4-tank rule at the Singapore checkpoint; passport with 6+ months validity; Singapore licence is valid in Malaysia.
- Insurance certificate covering West Malaysia (extension on the SG policy) plus goods-in-transit cover for hire-and-reward.
- Foreign commercial diesel vehicles: smoke below 50 HSU (Malaysia, from Apr 2026).
- Customs: Singapore export permit via TradeNet (declaring agent) and the Malaysian K1 filed by an RMCD-registered agent — the driver never files these.

### Price benchmarks (market, 2026)
- SG → JB: van / 1-tonne S$120–200; 3-tonne ≈ RM450 base (LorrySifu) + levy RM100 + forwarding RM120+ + customs forms RM100+ + toll RM20/80; 5-tonne S$300–500; 10-tonne / FTL S$500–800+. Same-day door to door; off-peak clearance 45–90 min, several hours at peak.
- SG → KL: no operator publishes a rate (Bills Logistic runs daily SG–KL, quote on request). Working estimate to validate in the pilot: van / 1-tonne S$450–650, 3-tonne S$650–900, 5-tonne S$900–1,300 per run (≈350 km each way, fuel, tolls, driver day). Get 3 driver quotes and 2 forwarder quotes before publishing anything.

### Product — Phase 1 (quote mode, 1–2 weeks of work)
1. Job form (web + app): destination country toggle "Malaysia" → city (Johor Bahru / Kuala Lumpur / other), delivery address free text + postcode, consignee company + contact, goods description, declared value, weight/pallets, "customs: TCG declaring agent / own agent (name)".
2. Pricing: always QUOTE mode (lib/pricing-mode.js ↔ app job-helpers.ts): drivers quote a total that includes tolls and levy; customs/forwarding fees are pass-through on the invoice.
3. Driver eligibility: `cross_border_ready` flag on express_users (self-declared VEP + Malaysia cover + passport; admin verifies from uploads). Only these drivers see and get pushed cross-border jobs.
4. Tracking: live location works across the border (mobile data); mark "at checkpoint" and "cleared" steps in the status flow.
5. Partners needed before the first job: one Singapore declaring agent (TradeNet) and one JKDM-registered agent in JB (K1). Candidates from the search: IFG Shipping (SG), LorrySifu (SG–JB daily, one-stop clearance), Bills Logistic (SG–KL daily). Ask each for agent-only pricing per shipment.
6. Phase 2 (after 10 pilot runs): fixed price table per vehicle/city like the SG modes.
